    Method, data, limits

    What is measured, what is modelled, what is assumed

    The dashboard is only useful if a judge can see where each number comes from. Real observations are labelled real; assumptions carry a source and a range and are never presented as measurements.

    How a decision is made

    re-solved hourly on a 24 h horizon, 15-minute steps
    Forecast

    Day-ahead PV and load with quantiles, corrected against the previous day's error.

    Optimise

    Mixed-integer programme over a 24 h horizon: battery, import cap, voltage band, flexible windows, outage reserve.

    Execute

    Apply the first hour. If the feeder limit binds, re-solve and correct in real time.

    Fall back

    If the optimiser or network is unavailable, hold reserve and protect the lifeline circuit.

    Limitations, stated not hidden

    five things this model does not claim
    No phase imbalance and no protection study. The feeder is a three-branch LinDistFlow approximation, not a network model.
    Unannounced outages cannot be forecast. They are handled by a held reserve, not by prediction.
    Second-life battery degradation and round-trip efficiency are simplified to a wear cost and one efficiency figure.
    Load is calibrated to Telangana LT-I consumption and a published Indian residential shape, not metered at a pilot.
    Every reliability number is simulated. A pilot would meter the same four quantities this page reports.
